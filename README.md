# Data Analyst Task 7: SQLite Sales Analysis

This project demonstrates basic SQL querying in Python to analyze sales data.

## Files
- `create_database.py`: Script to create the sample database
- `sales_analysis.py`: Main analysis script
- `sales_data.db`: SQLite database file
- `sales_chart.png`: Output visualization

## How to Run
1. First run `create_database.py` to generate the database
2. Then run `sales_analysis.py` to see the analysis

## Key Learnings
- Connecting Python to SQLite
- Writing basic SQL queries
- Using pandas for data analysis
- Creating simple visualizations
